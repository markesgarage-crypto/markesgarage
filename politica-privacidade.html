Política de Privacidade

Esta página explica que dados pessoais são recolhidos através deste site e como são tratados.

Responsável pelo tratamento

Que dados recolhemos

Apenas os que enviares no formulário de contacto: nome, email e mensagem.

Para que usamos os dados

Exclusivamente para responder ao teu contacto. Não os usamos para publicidade nem os vendemos a terceiros.

Com quem os partilhamos

O formulário é processado pelo Formspree, que recebe a mensagem e a reencaminha para o meu email. Este serviço pode tratar dados fora do Espaço Económico Europeu.

Durante quanto tempo guardamos

O tempo necessário para tratar o teu pedido. Podes pedir a eliminação a qualquer momento.

Os teus direitos

  • Acesso, retificação e apagamento dos teus dados;
  • Limitação e oposição ao tratamento;
  • Reclamação junto da Comissão Nacional de Proteção de Dados (CNPD).

Para exercer estes direitos, escreve para markesgarage@gmail.com.

Cookies

Este site não usa cookies de publicidade nem de análise. Guarda apenas, no teu browser, a indicação de que já viste o aviso de cookies. Os tipos de letra são carregados a partir do Google Fonts.
